One image summing up 23 November 2026's world news: the AI rout that hit Asia
(Kospi −3.3%), the UN chief's call to regulate AI before it's too late, and the
US lead over China falling to a record low — plus 28 more stories, a world map
with numbered pins, and a DATE CHECK box that keeps other days' news out.

## How to run

```sh
python3 main.py            # writes entry.png to $MAKEFUN_OUTPUT_DIR (default: out/)
```

`main.py` is stdlib-only (it parses the PNG header by hand) and never writes
next to itself, so it also works from a read-only copy of this repo.

## Contents

- `entry.png` — the 1024×1024 front page (31 stories, 6 regions)
- `draw.py` — the PIL script that drew `entry.png`
- `main.py` — stdlib-only copier/validator used by the grader
